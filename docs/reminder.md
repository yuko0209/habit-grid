# 記録忘れ防止リマインダー（iPhone）

作成: 2026-08-12

毎日の記録を忘れないための通知の設定手順。**アプリ側のコードは一切変更していない。**
iPhone の「ショートカット」アプリの機能だけで完結する。

---

## 1. なぜアプリに通知機能を実装しないのか

技術的にできないわけではないが、このアプリの構成だと割に合わない。

### iOS には「アプリ内で予約するローカル通知」がない

「毎日21時になったら通知を出す」をブラウザ側だけで予約する API（Notification Triggers）は
WebKit に載っていない。つまり **Web アプリが自分の力だけで時間指定の通知を出すことはできない。**

### Web Push は使えるが、サーバーが要る

iOS 16.4 以降、ホーム画面に追加した Web アプリなら Web Push を受け取れる。
ただし Web Push は「**サーバーが push を送りつける**」方式なので、毎日21時に送信する何かが
アプリの外に必要になる。具体的にはこれだけ足りない:

- Service Worker（push を受けて通知を描く）
- VAPID 鍵ペア
- 購読情報（PushSubscription）の保管場所
- 毎日決まった時刻に叩く定期実行（Vercel Cron か GitHub Actions）

これを入れると `docs/overview.md` の 1章にある「**バックエンドなし・全ページ静的**」という
このプロジェクトの前提が崩れる。しかも Vercel の Hobby プランの Cron は
**1日1回まで、かつ実行は指定時刻から1時間以内のどこか**（21時指定なら 21:00〜21:59 の間）
という精度なので、正確な時刻に鳴らしたいなら結局プラン変更か別の定期実行基盤が要る。

**ショートカットなら時刻はぴったり正確で、無料で、オフラインでも鳴る。**
個人で使うぶんにはこちらのほうが上なので、こうしている。

Web Push を実装する場合の考慮点は `overview.md` の 8章に残してある。

---

## 2. 設定手順

「ショートカット」アプリの**個人用オートメーション**で、毎日決まった時刻に通知を出す。

1. 「ショートカット」アプリを開く
2. 下部の **「オートメーション」** タブ
3. 右上の **「+」**
4. **「時刻」** を選ぶ
5. 時刻を設定（例: **21:00**）、繰り返しは **「毎日」**
6. **「すぐに実行」** を選ぶ ← ここが重要。「実行前に尋ねる」だと確認が挟まって鳴らない
7. 「次へ」
8. アクションを検索して **「通知を表示」** を追加
9. 通知の本文を入力（例: `今日のぶん記録した？`）
10. 「完了」

これで毎日21時に通知が出る。通知が来たら、**ホーム画面の Habit Grid アイコンから開いて**
記録する。

---

## 3. 注意点

### 通知をタップしてもアプリは開かない

通知をタップすると「ショートカット」アプリが開く。Habit Grid は自分でホーム画面の
アイコンからタップして開くこと。

### 「Appを開く」アクションは使えない

自動で Habit Grid を開かせたくなるが、**ホーム画面に追加した Web アプリ（Web クリップ）は
「Appを開く」の選択肢に出てこない。** iOS のアプリとして登録されていないため。

### 「URLを開く」で代用してはいけない

`https://habit-grid-9yb4.vercel.app` を「URLを開く」で開くと **Safari で開く。**
`overview.md` の 7章のとおり、iOS では Safari とホーム画面アプリで localStorage が
分かれることがあるので、**Safari 側で付けた記録がホーム画面アプリに出てこない**恐れがある。
記録が二重管理になるので、この方法は取らない。

### 「未記録の日だけ鳴らす」はできない

ショートカットからは localStorage の中身を読めないので、記録済みかどうかに関わらず毎日鳴る。
これが気になるほど鬱陶しくなったら、そのとき Web Push の実装を検討する。

## 4. 別案: 標準の「リマインダー」アプリ

ショートカットより通知が目立ち、消すまで残しておける方式。

1. 「リマインダー」アプリで新規リマインダーを作る（例: `Habit Grid に記録する`）
2. 詳細（ⓘ）→ **「日時」をオン**、時刻を設定
3. **「繰り返し」→「毎日」**

こちらは完了チェックを付けるまで残るので、「あとでやろう」で流してしまいがちなら向いている。
両方設定してもいい。
